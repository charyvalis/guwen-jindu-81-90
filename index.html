第81課　陶母責子　《世說新語》

📜 原文

陶公少時，作魚梁吏，嘗以坩鮓餉母。母封鮓付使，反書責侃曰：「汝為吏，以官物見餉，非唯不益，乃增吾憂也。」

📖 注釋

①魚梁吏：掌管漁業的官吏　②嘗：曾經　③坩：罐　④鮓：醃魚　⑤餉：送給　⑥反書：回信　⑦非唯：不但　⑧乃：反而　⑨見餉：餉我；「見」為代詞性助詞，省略「我」

🗣 語譯

陶侃年輕時，擔任管理漁業的官吏，曾派人送一罐醃魚給母親。陶母把醃魚封好交還來人，回信責備陶侃說：「你身為官吏，拿公家的東西送我，不但沒有好處，反而增加我的憂愁啊！」

📚 成語教室

主旨：陶母拒收公物並嚴厲責備，教導兒子為官要廉潔自持；陶母教子有方。 補充：「汝＝爾＝子＝若＝君」皆為第二人稱「你」。 補充：「見」放在動詞前，是代詞性助詞：以官物見餉＝以官物餉「我」。 補充：成語：假公濟私、公私不分；反面：一介不取、兩袖清風（形容官吏清廉）。 補充：名句：樹欲靜而風不止，子欲養而親不待（《韓詩外傳》）──感嘆人子欲盡孝時，父母已亡故。

📝 隨堂練習

  1. 本文主要在說明什麼？
    陶母退還公物並責備，教導兒子為官要廉潔。
  2. 陶侃派人送給母親的是什麼？
    「以官物見餉」，送的是公家的醃魚。
  3. 「陶公少時，作魚梁吏，嘗以坩鮓餉母」這段話表現出陶侃的什麼行為？
    以公家物品送母，是公私不分、假公濟私。
  4. 陶母說「乃增吾憂」，是在憂愁陶侃什麼？
    陶母擔心兒子貪取公物，終將遭禍。

第82課　盲子過河　《應諧錄》

📜 原文

有盲子道涉於溪，橋上失墜，兩手攀楯，兢兢握固，自分失手必墮深淵矣。過者告曰：「毋怖，第放下即實地也。」盲子不信，握楯長號。久之，力憊，失手墜地。乃自哂曰：「嘻！早知即實地，何久自苦耶！」

📖 注釋

①盲子：瞎子　②道涉：途中渡河　③楯：欄桿　④兢兢：戰戰兢兢，緊張的樣子　⑤握固：抓牢　⑥自分：自料　⑦墮：墜落　⑧毋怖：不要害怕　⑨第：只管、儘管　⑩憊：疲累　⑪哂：嘲笑

🗣 語譯

有個盲人經過一條乾涸的溪流，在橋上失足墜落，兩手抓住橋欄桿，戰戰兢兢抓得牢牢的，自以為一旦鬆手必會掉進深水潭。路人告訴他：「不要害怕，只管放手，下面就是實地了。」盲人不相信，緊握欄桿大聲呼號。時間久了，力氣用盡，一鬆手就掉到地上，於是自嘲：「唉！早知道下面是地面，何必讓自己辛苦這麼久呢？」

📚 成語教室

主旨：盲人不聽路人勸告，緊抓欄桿自討苦吃；許多恐懼只是自己嚇自己。 補充：「兢兢握固」＝膽戰心驚、不敢鬆懈。 補充：盲人不聽勸告、自討苦吃；寓意：許多恐懼只是自己嚇自己。 補充：風燭殘年：風中的燭火，比喻人近老年、殘生將盡（誤選項辨析）。

📝 隨堂練習

  1. 盲人「兩手攀楯，兢兢握固」，表現出的是什麼？
    兢兢握固＝戰戰兢兢，緊抓不放。
  2. 過路的人為什麼不對盲人伸出援手，拉他上來？
    橋下就是實地，盲人其實沒有危險。
  3. 盲人「久之，力憊，失手墜地」，結果是？
    墜地才發現是實地，什麼事也沒有。
  4. 本文中，盲人的處境可以說是？
    路人已告知放手即實地，他不信而自苦。

第83課　蒙人遇虎　《郁離子》

📜 原文

蒙人有衣狻猊之皮以適壙者，虎見之而走。返而矜，有大志。明日，服狐裘而往，復與虎遇。虎立而睨之，懼其不走也，叱之。虎乃搏而食之。

📖 注釋

①衣：穿（動詞）　②狻猊：獅子　③適：往、至　④壙：野外、郊外空闊處　⑤走：逃　⑥矜：驕傲　⑦服：穿　⑧裘：皮衣　⑨睨：斜著眼睛看　⑩叱：大聲責罵　⑪之：代詞，指披獅皮／狐裘的蒙人

🗣 語譯

有個蒙地人披著獅子皮到野外，老虎看到就逃跑。他回來後很驕傲，自認有大志。第二天，他穿著狐皮衣再去，又遇到老虎。老虎站在那兒斜著眼看他，他害怕老虎不逃走，便大聲斥罵，結果被老虎吃掉了。

📚 成語教室

主旨：蒙人誤把獅子皮的威嚴當成自己的實力，終究為虎所食；比喻不可倚仗外在的權勢而驕傲自大。 補充：第一次老虎怕的是獅子皮，不是人；蒙人誤把外在權勢當成自己的實力。 補充：「睨」＝斜視，表輕視、不在乎。 補充：成語：狐假虎威、養虎遺患、三人成虎（曾參殺人）；本文結局＝咎由自取。

📝 隨堂練習

  1. 蒙人最後終為虎所食，可以說是？
    因驕傲、誤以為虎怕自己而自招禍患。
  2. 蒙人第一次遇虎，「虎見之而走」是因為？
    老虎怕的是獅子皮，不是蒙人。
  3. 「虎立而睨之」顯示出老虎的態度是？
    睨＝斜視，表輕視、不在乎。
  4. 關於本文的敘述，哪一個正確？
    「謂虎畏己」「返而矜」，蒙人自以為老虎怕他。

第84課　蝜蝂傳　柳宗元

📜 原文

蝜蝂者，善負小蟲也。行遇物，輒持取，卬其首負之。背愈重，雖困劇不止也。其背甚澀，物積因不散，卒躓仆不能起。人或憐之，為去其負。苟能行，又持取如故。又好上高，極其力不已，至墜地死。

📖 注釋

①蝜蝂：一種黑色小蟲　②負：以肩背物　③輒：就、總是　④卬：抬起　⑤困劇：勞累不堪　⑥澀：不光滑　⑦卒：終於　⑧躓仆：跌倒　⑨苟：如果　⑩故：先前、從前

🗣 語譯

蝜蝂是一種喜歡背東西的小蟲，走路遇到東西就抓取，抬頭背在身上。背上越來越重，即使疲累不堪也不停。牠的背很粗糙，東西堆積不會散落，終於跌倒爬不起來。有人可憐牠，幫牠拿掉背上的東西；但只要能爬行，牠又像先前一樣去抓東西。牠又愛往高處爬，用盡力氣不停止，直到掉在地上摔死。

📚 成語教室

主旨：蝜蝂貪得無厭、愈背愈重，又愛往高處爬，終致墜地而死；諷刺貪得無厭、自取滅亡的人。 補充：「負」：以肩背物，V（負荊請罪）；辜負＝背棄、違背；忘恩負義＝背棄、違背，V；如釋重負＝責任，N。 補充：諷刺貪得無厭、自取滅亡的人。 補充：「輒」：每、總是（動輒得咎）；就、即（淺嘗輒止）。

📝 隨堂練習

  1. 「蝜蝂者，善負小蟲也」，句中的「負」意近下列哪一個「負」？
    負＝以肩背物；忘恩負義是背棄，如釋重負指責任。
  2. 本文的主旨是？
    蝜蝂愈背愈重仍不止，諷刺貪得無厭者。
  3. 蝜蝂「躓仆不能起」的原因是？
    「物積因不散」，負擔過重而跌倒。
  4. 本文中，蝜蝂的結局是？
    貪取、貪高，終至墜地而死。

第85課　王荊公獨遊　《青瑣高議》

📜 原文

王荊公介甫，退處金陵。一日，幅巾杖屨，獨遊山寺，遇數客盛談文史，詞辯紛然。公坐其下，人莫之顧。有一人徐問公曰：「亦知書否？」公唯唯而已。又問公何姓，公拱手答曰：「安石姓王。」眾人惶恐，慚俯而去。

📖 注釋

①王荊公：王安石，字介甫，北宋政治家、文學家　②退處：辭去職務居住　③幅巾：以絹帛束髮　④屨：麻鞋　⑤盛談：高談闊論　⑥紛然：雜亂紛紛的樣子　⑦顧：關注、照應　⑧唯唯：恭敬應答聲　⑨拱手：兩手合抱行禮　⑩惶恐：惶懼不安

🗣 語譯

王安石辭官後住在金陵。一天，他頭上用一條絹巾束髮，拄著枴杖、穿著麻鞋，獨自遊覽山寺，遇見幾位客人高談文史，辯論紛紛。王安石坐在一旁，沒有人理會他。其中一人慢慢問他：「你也讀過書嗎？」王安石只恭敬應了一聲。又問他姓什麼，他拱手回答：「我姓王，叫安石。」眾人惶恐不安，慚愧低著頭離開了。

📚 成語教室

主旨：王安石平日不擺架子、衣著樸素，眾人以貌取人，得知其身分後慚愧而去；告誡人不可以貌取人。 補充：「人莫之顧」＝人莫顧之（倒裝）；「顧」關注、照應。 補充：「顧」多義：看、張望（環顧）、回首（後顧之憂、伯樂一顧）、拜訪（三顧茅廬）、關注（顧此失彼）、反而（顧不如蜀鄙之僧哉）。 補充：眾人有眼不識泰山，以貌取人。

📝 隨堂練習

  1. 「盛談文史，詞辯紛然」是在形容什麼？
    盛談、紛然＝高談闊論、議論紛紛。
  2. 眾人初見王荊公坐在一旁，反應是？
    「人莫之顧」，沒人理會他。
  3. 「亦知書否？」是什麼語氣？
    以為他不過是普通人，語帶輕視。
  4. 「眾人惶恐，慚俯而去」的原因是？
    沒想到眼前這位就是大名鼎鼎的王安石。

第86課　鴞將東徙　《說苑》

📜 原文

梟逢鳩，鳩曰：「子將安之？」梟曰：「我將東徙。」鳩曰：「何故？」梟曰：「鄉人皆惡我鳴，以故東徙。」鳩曰：「子能更鳴可矣；不能更鳴，東徙猶惡子之聲。」

📖 注釋

①梟（鴞）：貓頭鷹　②鳩：斑鳩　③之：動詞，到、往　④徙：遷移　⑤惡：討厭　⑥更：改變　⑦猶：還是

🗣 語譯

貓頭鷹遇到斑鳩，斑鳩問：「你要到哪裡去？」貓頭鷹說：「我要搬到東邊去。」斑鳩問：「為什麼？」貓頭鷹說：「鄉里的人都討厭我的叫聲，所以要往東搬。」斑鳩說：「你如果能改變叫聲就好了；不能改變，搬到東邊，那裡的人還是會討厭你的聲音。」

📚 成語教室

主旨：梟以為搬家就能擺脫被討厭，鳩點出問題在自己的叫聲；遇到問題要先反求諸己，從根本解決。 補充：「之」四種用法：助詞（的）、助詞（無意義）、動詞（到）、代詞；「子將安之」之＝到。 補充：「以故」＝因此（原因、理由）。 補充：寓意：遇到問題要先反求諸己，從根本改變。

📝 隨堂練習

  1. 本文主要說明什麼道理？
    不改變叫聲，搬到哪裡都被討厭。
  2. 本文中，梟為什麼要東徙？
    「鄉人皆惡我鳴」。
  3. 對於梟的問題，該如何解決？
    鳩建議：能更鳴可矣。
  4. 「子能更鳴可矣」，「更鳴」的意思是？
    更＝改變。

第87課　水喻　蘇軾《東坡全集》

📜 原文

南方多沒人，日與水居也，七歲而能涉，十歲而能浮，十五而能沒矣。夫沒者豈苟然哉！必將有得於水之道者。日與水居，則十五而得其道；生不識水，則雖壯，見舟而畏之。故北方之勇者，問於沒人，而求其所以沒，以其言試之河，未有不溺者也。

📖 注釋

①沒人：會潛水的人　②居：相處　③涉：徒步渡水　④浮：浮游　⑤沒：潛入水中　⑥苟然：隨隨便便　⑦畏：恐懼　⑧於：向　⑨溺：淹沒

🗣 語譯

南方有很多能潛水的人，天天跟水相處，七歲就能徒步渡水，十歲能浮游，十五歲就能潛入水中。這些會潛水的人，難道是隨隨便便做到的嗎？一定是領悟到水的規律。天天和水相處，十五歲就能掌握水性；生來不認識水，即使壯年，看到船也害怕。所以北方勇敢的人，向南方善潛水的人請教，按照他們說的方法到河裡試驗，沒有不淹死的。

📚 成語教室

主旨：南方人日日與水相處才善於潛水，北方勇者只聽不練，下水必溺；學習必須親身實踐，才能掌握事物規律。 補充：「於」：向（問於沒人）、對於、在、比、給、被。 補充：冒然／貿然：輕率、魯莽的樣子。 補充：主旨：學習必須親身實踐，才能掌握事物的規律。 補充：句式：未有不溺者也＝雙重否定。

📝 隨堂練習

  1. 本文的主旨是？
    北方勇者只問不練，下水必溺。
  2. 「南方多沒人」的原因是？
    「日與水居」，所以十五而得其道。
  3. 「見舟而畏之」顯示出北方的人？
    生不識水，見船就害怕。
  4. 北方勇者學潛水「未有不溺者也」，原因是？
    只聽不練，貿然下水。

第88課　徙木立信　《史記》

📜 原文

令既具，未布，恐民之不信，已乃立三丈之木於國都市南門，募民有能徙置北門者予十金。民怪之，莫敢徙。復曰：「能徙者予五十金！」有一人徙之，輒予五十金，以明不欺。卒下令。

📖 注釋

①令：指商鞅變法的條令　②具：完備　③布：公布　④丈：長度單位　⑤募：招募　⑥徙：移　⑦置：放　⑧予：給　⑨怪：對…感到奇怪　⑩輒：就　⑪卒：終於

🗣 語譯

新法令已備妥，還沒公布，商鞅擔心百姓不相信，就在國都市場南門豎立一根三丈高的木頭，招募百姓有能搬到北門的，給十金。百姓覺得很奇怪，沒有人敢去搬。又說：「能搬的給五十金！」有一個人把木頭搬走，就給他五十金，以此表明不欺騙百姓。最後才頒布法令。

📚 成語教室

主旨：商鞅以徙木賞金取信於民，再頒布新法令；為政者言出必行，才能取信於百姓。 補充：「信」＝誠實不欺（信用）；徙木立信＝言出必行，建立誠信於百姓。 補充：「恐」＝擔心（為動用法：擔心百姓不信）。 補充：「輒」＝就；「卒」＝終於；「復」＝又。

📝 隨堂練習

  1. 商鞅公布法令前，先招募民眾做什麼？
    徙木立信。
  2. 「徙木立信」的「信」，意思是？
    信＝誠實不欺、信用。
  3. 「民怪之」的意思是？
    怪＝對…感到奇怪（意動用法）。
  4. 後人用「徙木立信」來比喻？
    徙木立信：言出必行，取信於民。

第89課　鴝鵒學舌　《荻箕子》

📜 原文

鴝鵒之鳥，出於南方。南人羈而調之，能效人言；但能效數聲而止，終日所唱，惟數聲也。蟬鳴於庭，鳥聞而笑之。蟬曰：「子能人言，甚善。然，子所言者，未嘗言也，曷若我自鳴其意哉！」鳥俯首而慚，終身不復效人言。

📖 注釋

①鴝鵒：八哥鳥　②羈：訓練、拘繫　③調：訓練、指導　④效：模仿　⑤惟：只、只有　⑥曷：何、哪裡　⑦俯首：低頭　⑧慚：慚愧

🗣 語譯

八哥生在南方，南方人把牠養起來訓練，牠能模仿人說話，但只能學幾聲就停，整天所唱只有那幾聲。蟬在庭院鳴叫，八哥聽到就笑牠。蟬說：「你能說人話，很好。但你說的都不是自己想說的，哪裡比得上我自己鳴叫出自己的心意呢！」八哥低頭慚愧，一輩子不再學人說話。

📚 成語教室

主旨：鴝鵒只會模仿人說話，被蟬譏為沒有自己的意思；比喻人云亦云、沒有主見的人。 補充：成語：人云亦云、鸚鵡學舌＝沒有獨立見解，只會盲從。 補充：「於」：在（鳴於庭）。 補充：「汝＝爾＝子＝若＝君」第二人稱。

📝 隨堂練習

  1. 在本文中，鴝鵒鳥經過訓練後，可以？
    「能效人言」，只是模仿。
  2. 「鳥聞而笑之」的「之」指的是？
    聞蟬鳴而笑蟬，之＝蟬。
  3. 蟬為何說鴝鵒「未嘗言也」？
    只會學人說話，沒有說出自己的意思。
  4. 本文的寓意是？
    人云亦云者如鴝鵒學舌，沒有主見。

第90課　捨本逐末　《戰國策》

📜 原文

齊王使使者問趙威后，書未發，威后問使者曰：「歲亦無恙耶？民亦無恙耶？王亦無恙耶？」使者不說，曰：「臣奉使使王，今不問王，而先問歲與民，豈先賤而後尊貴者乎？」威后曰：「不然。苟無歲，何以有民？苟無民，何以有君？故有問，舍本而問末者耶？」

📖 注釋

①威后：趙威后　②發：拆開　③歲：一年的農業收成　④恙：疾病、災禍　⑤說：喜悅，通「悅」　⑥賤：指百姓、收成　⑦苟：假如　⑧舍：捨棄　⑨末：不重要、非根本

🗣 語譯

齊王派使者問候趙威后，信還沒拆開，威后先問使者：「今年收成沒有災害吧？百姓沒事吧？齊王也平安吧？」使者不高興，說：「我奉命出使，現在不先問大王，卻先問收成和百姓，難道是先問卑賤的、後問尊貴的嗎？」威后說：「不是這樣。如果沒有收成，哪來百姓？沒有百姓，哪來國君？所以怎會捨棄根本而去問枝節呢？」

📚 成語教室

主旨：趙威后先問歲收、百姓，後問齊王，認為百姓才是國家的根本；做事要分清本末先後，不可捨本逐末。 補充：名句：民為貴，社稷次之，君為輕（《孟子》）──百姓最重要。 補充：「說」通「悅」；「苟」＝假如。 補充：先後：歲收→百姓→齊王；「末」＝齊王（非根本）。

📝 隨堂練習

  1. 威后問使者，「使者不說」，意思是？
    說＝悅。
  2. 使者說「豈先賤而後尊貴者乎」，「尊貴者」是指？
    使者認為君王尊貴，百姓與歲收卑賤。
  3. 趙威后問候的先後順序是？
    歲亦無恙耶？民亦無恙耶？王亦無恙耶？
  4. 趙威后認為不能「舍本而問末」，「末」是指？
    歲收→百姓→君，君為末。

選擇題（每題 5 分，共 75 分）。粗體加底線的字為題目所問的字。直接點選答案作答。

  1. 「己所不欲，勿施『於』人」的「於」，意思是？
    於：介詞，給；施於人＝施給別人。
  2. 「苛政猛『於』虎」的「於」，意思是？
    於：置於形容詞之後表示比較，意思是「比」。
  3. 「北方之勇者，問『於』沒人」的「於」，意思是？
    於：介詞，向；向會潛水的人請教。
  4. 「蟬鳴『於』庭」的「於」，意思是？
    於：介詞，在（表地點）；蟬在庭院鳴叫。
  5. 「動『輒』得咎」的「輒」，意思是？
    輒：副詞，每、總是；動輒得咎＝一有舉動就犯過。
  6. 「有一人徙之，『輒』予五十金」的「輒」，意思是？
    輒：副詞，就、即；有人搬了，就給他五十金。
  7. 「溫『故』知新」的「故」，意思是？
    故：名詞，已學得的知識、學問。
  8. 「明知『故』犯」的「故」，意思是？
    故：副詞，有意地、存心地。
  9. 「人莫之『顧』」的「顧」，意思是？
    顧：關注、照應；人莫之顧＝沒有人理會他。
  10. 下列「顧」字，何者意思為「拜訪」？
    三顧茅廬：劉備三次拜訪諸葛亮。
  11. 「子將安『之』」的「之」，詞性與意思是？
    安之＝到哪裡去，之：動詞，到。
  12. 「鳥聞而笑『之』」的「之」，指的是？
    鴝鵒聽到蟬鳴而笑蟬，之＝蟬。
  13. 「以官物『見』餉」的「見」，用法是？
    以官物見餉＝以官物餉我。
  14. 「明月來『相』照」的「相」，用法是？
    明月來相照＝明月來照我，動作是單方面的。
  15. 下列何者不是第二人稱代詞？
    予＝余＝吾，是第一人稱「我」。
